# 资产页「批量录入模式」设计

> 日期：2026-06-21 · 状态：待实现

## 背景与问题

录入某个月所有资产的月度快照，当前流程是：
**资产页 → 点资产 → 详情页 → 点「添加记录」→ 填 3 个字段 → 保存 → 返回 → 返回 → 下一个资产……**

资产一多，"一个个点开"的导航成本极高。本设计在**资产页**上加一个就地的批量录入模式，把 N 次「点开-填-返回」压缩成一屏内的展开/收起，最后统一提交。

不改动 `add-record` modal——它仍是从资产详情页编辑单条快照的入口；本特性是资产页上的**新增**能力。

## 目标

- 在资产页一屏内完成"一次更新一批资产本月（或任意月）净值"
- 支持补录/修改过去任意月份
- 已有快照可在原值上修改（"补录"与"修改"是同一动作）
- 单次操作可丢弃，避免误写

## 非目标

- 不替换 `add-record` modal
- 不做跨多个月份的批量录入（一次只针对一个选定月份）
- 不改快照数据模型 / repo（复用现有查询）

## 交互设计

### 普通模式

- 资产页顶部新增 **「录入」按钮**（入口）。
- 卡片点击行为维持现状：跳资产详情页。

### 录入模式

点「录入」进入。顶部头部**变形**为操作栏：

```
[ 取消 ]      ‹  2026 年 6 月  ›      [ 提交 (N) ]
```

- **取消**（左）：丢弃所有草稿，退出录入模式。
- **年月选择器**（中）：左右箭头切月，默认当前月；点中间标签快速跳选年月。切月前若有未提交改动 → 弹确认，确认后清空草稿再切。
- **提交 (N)**（右）：N = 有改动的资产数；N=0 时置灰。
- 卡片点击行为切换为「就地展开成录入卡」。
- 提交成功或取消后 → 退出录入模式，恢复浏览。

### 展开录入卡

点资产卡片 → 就地展开为录入卡，内容（默认三框，与 `add-record` 一致）：

- 顶部参考行：**上月净值 XXX**
- **净值 / 流入 / 收益** 三个输入框 + **「自动计算」开关**（收益 = 净值差 − 流入；切换/输入逻辑同 `add-record`）
- 已有该月快照时，**预填已有值**
- 卡片底部两个小按钮：

```
                              [ ✗ ]   [ ✓ ]
```

  - **✗（取消编辑）**：丢弃这张卡的草稿（从草稿 Map 移除，N 减 1）并收起；已有快照的卡片恢复显示原已有值，不影响数据库。
  - **✓（收起）**：保留草稿并收起，计入 N。

### 手风琴

同一时刻只展开一张卡。展开第二张时第一张自动收起，按 **✓ 语义**处理（保留草稿）。

### 草稿持久

草稿存活在资产页状态里，与展开/收起无关。第二次展开同一张卡 → 从草稿回填上次填的值，**信息不丢**。三个收起路径语义：**✗ = 弃**、**✓ = 留**、**展开别张 = 留（自动）**。

## 数据流

资产数量在个人理财场景下很小，采用如下策略：

- **进入录入模式 / 切月时**：调一次 `listSnapshotsByDate(selectedMonth)`（已存在，返回该月所有快照含账户/资产名），用于：
  1. 卡片右侧显示「已有 ✓」标记；
  2. 展开时预填已有值。
- **上月净值**（`getLastSnapshotBefore`）：按需查询——展开某卡片时才查该单个资产，避免每次切月跑 N 次查询。
- **草稿状态**：`Map<assetId, Draft>`，`Draft = { netWorth, inflow, profit, autoFill }`；外加单独的 `expandedAssetId`（手风琴）。只有用户实际填过/改过的资产进 Map，计入 N。
- **提交**：遍历草稿 Map，逐个 `upsertSnapshot(assetId, selectedMonth, n, i, p)`；净值非数字的项跳过并提示；完成后 `loadData()` 刷新并退出录入模式。
- **切月确认**：草稿 Map 非空时切月 → `confirmAsync`（`src/utils/dialog.ts`，跨平台）确认再清空。

## 组件分解

`assets.tsx` 当前精简（~150 行），加入录入模式后会显著膨胀。为保持单元边界清晰：

- **`src/utils/snapshot-calc.ts`（新）**：抽出自动计算的纯函数（`profit = netWorth − lastNetWorth − inflow` 及其反推），供 `add-record.tsx` 与新录入卡共用，消除重复、保证单一真相源。`add-record.tsx` 顺手改为引用此 helper。
- **`src/components/MonthSelector.tsx`（新）**：年月选择器（箭头切月 + 点击跳选）。受控组件，`value` / `onChange`。
- **`src/components/AssetEntryCard.tsx`（新）**：展开录入卡。props：资产信息、上月净值、初始草稿、`autoFill`、`onChange(draft)`、`onCancel`（✗）、`onCollapse`（✓）。自身不碰数据库，纯受控。
- **`app/(tabs)/assets.tsx`（改）**：持有录入模式状态（`entryMode` / `selectedMonth` / 草稿 Map / `expandedAssetId`）、变形头部、数据加载与提交编排。

## 错误处理

- 提交时净值非法（非数字）→ 该项跳过并 `notify` 提示哪些资产未保存。
- 切月 / 取消时若有草稿 → `confirmAsync` 防误丢。
- `listSnapshotsByDate` / `upsertSnapshot` 失败 → 沿用现有错误提示路径，不静默吞掉。
